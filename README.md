# 🎮 Graph Quest: Save Fully Automated Manually™

**Don't demo that your agent works. Prove that it fails safely.**

Graph Quest is a free interactive learning game about **Atlassian Rovo agents, Teamwork Graph and safe enterprise AI**.

You join a fictional company that has just switched on Rovo.

Unfortunately, Legal is already involved.

You'll make decisions about Teamwork Graph, permissions, agent identity, prompt injection, Forge, MCP, subagents, evaluations and autonomy — and discover that a successful demo is not necessarily evidence that an agent is ready for production.

## The idea

AI demos usually prove that an agent works when everything goes right.

Graph Quest asks a different question:

**What happens when it shouldn't?**

Identity. Permissions. Failure behaviour. Trust boundaries. Evaluations. Autonomy.

Because autonomy should be earned, not assumed.
